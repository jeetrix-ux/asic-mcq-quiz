# ASIC MCQ Practice

200 practice MCQs on the ASIC design flow, static timing analysis, and RTL design and verification. Every answer has a one-line solution and the topic or slide of the notes it comes from.

**Live:** https://jeetrix-ux.github.io/asic-mcq-quiz/

- **Learn mode:** see the answer, solution and source after each question.
- **Test mode:** answer a set, then get your score and a review of what you missed.
- Run everything, one part, one section, a random 25, only the ones you missed, or only the ones you haven't tried yet.
- Keyboard: `A`–`D` or `1`–`4` to answer, `Enter` / `→` for next, `←` for previous, `Esc` to go back to the sections.
- Progress is saved in your browser (`localStorage`).
- The *Where the slides are wrong* page lists the STA-deck errors, giving both the slide's version and the correct one.

Plain HTML/CSS/JS with no build step. `data.js` is generated by `tools/build_data.py` from the practice-sheet sources.
