# MCQ Practice: ASIC flow and analog design

Two 200-question practice banks for MCQ tests. Every answer has a one-line solution and the part of the notes it comes from. Use the switcher at the top to change subject.

**Live:** https://jeetrix-ux.github.io/asic-mcq-quiz/ · **Analog bank directly:** https://jeetrix-ux.github.io/asic-mcq-quiz/#analog

| Bank | Covers |
|---|---|
| ASIC flow, STA, verification | ASIC design flow (74 topics), the 147-slide STA reference, RTL design and design-verification basics |
| Analog design | The flow from requirements to GDS, diode and MOSFET physics, second-order effects, interconnect R/C, crosstalk, EM/IR, matching and layout-dependent effects, latch-up and the LDO. More than half the questions are small numericals |

- **Learn mode:** see the answer, solution and source after each question.
- **Test mode:** answer a set, then get your score and a review of what you missed.
- Run everything, one part, one section, a random 25, only the ones you missed, or only the ones you haven't tried yet.
- Keyboard: `A`–`D` or `1`–`4` to answer, `Enter` / `→` for next, `←` for previous, `Esc` to go back to the sections.
- Progress is saved in your browser (`localStorage`), separately for each bank.
- ASIC bank: the *Where the slides are wrong* page lists the STA-deck errors. Analog bank: the *Notation traps* page lists symbols the course uses for two things.

Plain HTML/CSS/JS with no build step. `data.js` (ASIC) is generated by `tools/build_data.py` from the practice-sheet sources. `data-analog.js` is hand-written: in each `q(...)` call the correct option comes first, and the app shuffles the options on screen.
